# 장 데이터 형식

`chNN.js` 한 파일이 장 하나입니다. `window.LESSONS[N] = { ... }`로 넣고, `learn.js`가 그립니다. 본보기는 `ch04.js`입니다.

## 원칙

- **글에 있는 사실만 씁니다.** 설명·지표·흐름 이름·배지에 나오는 숫자, 상태 이름, 코드 이름은 그 장의 글(`content/<slug>/index.md`)에 그대로 있어야 합니다. `check-lessons.js`가 숫자와 `` `코드` ``가 글에 있는지 대조합니다. 글에 없는 시간·건수·비율을 그림을 위해 만들지 않습니다.
- 그림은 단순화해도 되지만(서버 한 대를 상자 하나로), 글과 다른 순서나 없는 호출을 그리지 않습니다.
- 말투는 블로그와 같은 합니다체입니다. 결정 단계의 첫 문장은 "이 장에서는 ~하기로 했습니다."로 씁니다.

## 장

| 필드 | 뜻 |
|---|---|
| `slug` | 글 주소(`content/<slug>/`) |
| `branch` | 코드 브랜치(`chapter-NN`) |
| `title` | 글 제목 그대로 |
| `goal` | 이 장에서 하는 일 한 문장 |
| `learn` | 오른쪽 아래 "익히는 것" 목록. `{ text, step }` — `step`(0부터)을 지나면 체크됩니다 |
| `nodes` | `{ id, kind, label, sub, subMono, x, y, absent }`. `kind`는 client·server·pg·db·kafka·scheduler·service·ops |
| `edges` | `[a, b]` 또는 `[a, b, { dashed: true }]`. 모든 단계에 깔리는 선 |
| `steps` | 단계 목록(8~16개) |

화면은 1000 × 560입니다. 노드 가운데는 x 85~915, y 100~470 안에 두고, 노드끼리 가로 200 또는 세로 150 넘게 떨어뜨립니다. 배지가 노드 위에, 메모가 노드 아래에 붙으므로 그 자리를 비워 둡니다. 선이 다른 노드를 지나거나 서로 엇갈리지 않게 놓습니다.

## 단계

| 필드 | 뜻 |
|---|---|
| `short` | 아래 단계 막대 이름(8자 이내) |
| `tag` | 출발·문제·결정·비교·결과·한계·정리 |
| `title` | 오른쪽 제목 |
| `src` | 근거가 된 글의 소제목(`##`·`###` 줄 그대로). "글에서 보기" 링크가 됩니다 |
| `body` | 문단 배열(2개 안팎). `` `코드` ``와 `**굵게**`만 씁니다 |
| `note` | "알아 둘 것" 상자(선택). 비용이나 조건 |
| `changed` | "바뀐 것" `[['+', '...'], ['~', '...'], ['-', '...']]`(선택) |
| `metrics` | 위쪽 지표 `{ label, value, tone }`. tone은 good·warn·bad. 없으면 앞 단계 것을 이어 씁니다 |
| `hide` | 이 단계에 아직 없는 노드(흐리게, `absent` 문구) |
| `focus` | 굵게 보일 노드 |
| `edges` | 이 단계에만 더하는 선 |
| `states` | 시작할 때 노드 상태 `{ id: { badge, tone, note, noteTone } }`. tone은 ok·warn·bad·info·muted |
| `flows` | 차례대로 움직이는 흐름. 배열 안 배열은 동시에 움직입니다 |

흐름 하나는 `{ from, to, kind, label, mono, cut, slow, then }`입니다.

- `kind`: req(요청) · res(응답) · fail(실패·시간 초과) · event(이벤트·메시지) · write(DB 기록) · query(조회)
- `cut: true`: 가는 중에 끊깁니다(✕). 시간 초과·기록 실패
- `then`: 도착하면 바뀌는 노드 상태. `shake: true`면 노드가 흔들립니다
- `from` 대신 `at: 노드`를 주면 그 노드 자리에서 일어나는 일(상태 변화·메모)입니다
