# 강의 수강 노트 변환 규칙

원본 루트: `/Users/taeyoung/Downloads/Export-c1198803-3981-4e38-9804-6e391f86aed6/`
대상: `/Users/taeyoung/blog/tech-blog/content/<slug>/index.md`

작업 목록은 호출하는 쪽에서 `원본경로 → slug` 형태로 건네받습니다. 원본은 노션에서 내보낸 `.md` 파일 하나뿐이고, 별도의 `meta.md`는 없습니다.

## 출력 형식

```
---
title: "글 제목"
tags: ["태그1", "태그2"]
summary: "한 문장 요약"
---

본문...
```

## 규칙

1. **이미지는 모두 제외합니다 (가장 중요)**
   원본의 이미지는 유료 강의 슬라이드를 캡처한 것이라 블로그에 실을 수 없습니다. `![...](...)` 링크를 **전부 삭제**하고, `images/` 폴더도 만들지 마세요.
   - 이미지에 기대고 있던 문장("아래 그림과 같이", "다음 그림에서 보듯")은 그림 없이도 읽히도록 고쳐 쓰세요. 그림이 설명하던 내용이 본문에 이미 있으면 그대로 두고, 없으면 문장을 자연스럽게 다듬습니다.
   - 그림이 사라져 설명이 비어 버리는 자리에 내용을 **지어내지 마세요.** 원문에 있는 텍스트만 씁니다.

2. **문체는 존댓말(…합니다/…입니다)로 통일합니다.**
   원본은 강의를 들으며 적은 개조식 메모라 "~한다", "~임" 같은 형태가 섞여 있습니다. 서술문은 존댓말로 바꾸고, 항목 나열(명사형 종결)은 그대로 두어도 됩니다.

3. **내용을 보존합니다.** 요약하거나 생략하지 마세요. 헤딩, 코드 블록, 표, 링크를 유지합니다. **코드 블록 내부는 절대 수정하지 않습니다**(오타 포함).

4. **노션 잔여물을 제거합니다.** 맨 위 H1 제목 줄과 속성 줄(`상태:`, `담당자:`, `날짜:`, `속성:`, `속성 1:`, `만든날짜:`, `수정날짜:`, `순서:`)을 지웁니다. 노션 내부 링크(`notion.so`, `.md` 상대경로)도 제거하거나 문맥에 맞게 풀어 씁니다.

5. **제목(title)** — 원본 제목에서 `[Spring JPA]`, `[클린 코드 with Java]` 같은 대괄호 접두어와 앞머리 번호를 떼고, 내용을 나타내는 제목으로 다듬습니다. 화면에는 카테고리·시리즈 라벨이 따로 붙으므로 접두어는 군더더기입니다. `⭐` 같은 장식 문자도 제거합니다.
   - 예: `[Spring JPA] JPA 엔티티 매핑` → `"JPA 엔티티 매핑"`
   - 예: `4 [클린 코드 with Java] 3단계 - 자동차경주` → `"자동차 경주 — 3단계"`

6. **tags** — 글 내용에 맞게 3~6개를 새로 만듭니다.

7. **summary** — 목록에 노출될 한 문장을 존댓말로 씁니다(60~120자). 무엇을 다루는 글인지 정확히 알려 주세요.

8. **헤딩 구조** — 본문 최상위 헤딩은 `##`부터 시작합니다. 원본이 `###`만 쓰거나 `#`을 섞어 썼다면 한 벌로 정리하세요.

9. 오탈자와 띄어쓰기 오류는 고칩니다(예: `오케이스트레이션`→`오케스트레이션`, `프로잭트`→`프로젝트`, `맵핑`→`매핑`, `스플링`→`스프링`).

10. frontmatter의 문자열은 큰따옴표로 감싸고 내부 큰따옴표는 `\"`로 이스케이프합니다. `summary`는 반드시 한 줄입니다.

## 확인

작업을 마치면 작성한 파일에 `![`로 시작하는 이미지 링크가 하나도 남아 있지 않은지 `grep`으로 확인하세요.
