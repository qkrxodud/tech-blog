이전에 [11장 시스템 (2)](../clean-code-ch12-systems-2/)에 대해 작성하였습니다. 현재 클린 코드는 11장까지 정리를 완료하였습니다.

다만 최근까지 Flutter 위주로 공부하고 실무에 적용하다 보니, Spring 어노테이션의 기능들을 확실히 알지 못한 상태에서 단편적으로 이해하고 넘어간다는 느낌을 강하게 받았습니다.

12장 이후부터는 Spring의 어노테이션과 각각의 기능들이 자바 기반으로 나와 있습니다. 이를 좀 더 정확히 알고 전달하기 위해 Spring을 공부한 후 12장부터 다시 진행하려고 합니다.

현재 인프런을 통해 인강을 듣고 직접 코드를 작성하고 있으며, 이 내용 또한 블로그에 올리고 완료되는 즉시 12장부터 다시 진행하도록 하겠습니다.
